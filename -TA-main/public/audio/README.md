Add MP3 files here only if you own them or have permission to use them.

To connect a track:
1. Open the birthday settings and go to the lyrics tab.
2. Expand the track, enter its path (for example, `/audio/birthday-song.mp3`), and save.
3. Edit each lyric line and its start time in seconds to match the recording.

The first lyric usually starts at 0 seconds. File names and paths are case-sensitive when deployed.
